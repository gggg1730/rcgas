# Cold-Gas Roadster

냉가스 노즐 8개를 단 2.8 kg짜리 차를 직접 몰고, 띄우고, 뒤집는 게임입니다. 착지와 플립은 강화학습(PPO)으로 학습한 자동조종이 맡습니다. 물리는 MuJoCo로 계산합니다.

**브라우저에서 바로 하기:** https://gggg1730.github.io/rcgas/
(웹 버전은 같은 게임을 자바스크립트로 옮긴 것입니다. 아래 [웹 버전](#웹-버전) 참고)

---

## 실행

Python 3.10 이상, macOS(Apple Silicon)에서 확인했습니다.

```
cd rl_landing
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python game.py
```

전용 창을 직접 띄우므로 `mjpython`이 아니라 `python`으로 실행합니다. 창이 뜨면 한 번 클릭해 포커스를 잡은 뒤 키를 누르세요.

```
.venv/bin/python game.py --speed 0.5      # 0.5배속으로 시작
```

공중에서 키를 놓으면 자동으로 수평이 되고, 수평 속도를 죽인 뒤 그 자리에 떠 있습니다 (드론의 자세 유지 모드와 같습니다).

## 코스

출발점(0 m) → 경사로(3 m) → 단상 30 cm(10 m) → 단상 60 cm(12.5 m) → 벽(15 m) → 착지 패드(17.5 m)

경사로를 빠르게 타면 날아오릅니다. 단상 위에서도 RL 착지와 플립이 동작합니다.

## 기체

| 항목 | 값 |
|---|---|
| 크기 · 질량 | 40 × 20 × 10 cm, 2.8 kg (고압 공기 탱크 0.8 kg 포함) |
| 아래 노즐 | 바퀴 자리 4개, 각 20 N (합 80 N, 무게 27.5 N) |
| 옆 노즐 | 4개, 각 2 N (회전, 옆 이동) |
| 밸브 지연 | 15 ms |
| 제어 · 물리 주기 | 100 Hz · 1 kHz |
| 가스 | 1 N당 2.6 g/s. 탱크 190 g이면 떠 있기만 해도 약 2.5초 |

## 강화학습이 하는 일

| 키 | 정책 (모델 파일) | 학습 내용 | 평가 성공률 |
|---|---|---|---|
| L, X | 착지 (`ppo_wheels_wild.zip`) | 무작위로 던져진 상태(뒤집힘, ±360°/s 회전 포함)에서 수평·저속 착지 | 일반 던지기 100%, 막 던지기 63% |
| F | 옆구르기 (`ppo_jumpflip.zip`) | 바닥에서 뛰어올라 한 바퀴 돌고 착지 | 90% |
| G | 앞구르기 (`ppo_frontflip.zip`) | 35 cm 이상 뛰어올라 앞으로 돌고 착지 | 87% |

게임은 학습된 정책을 학습 환경 밖에서도 쓰기 위해 몇 가지를 맞춥니다.

- **단상 위에서:** 높이 입력으로 "바로 아래 지면까지 거리"를 넣어, 평지에서 학습한 정책이 단상 위에서도 그대로 동작합니다.
- **공중 플립:** 플립 정책은 낮은 높이에서만 돌아 봤기 때문에, 공중에서는 높이를 0.25 m로 알려 줍니다. 한 바퀴를 돌면 비행 보조가 넘겨받아 다시 정지 비행합니다.
- **마지막 착지:** RL·플립·점프 모두 땅 근처에서 어느 정도 수평이 되면 자동 착지가 넘겨받습니다. 멈추거나 다시 올라가지 않고 내려오면서 수평을 맞춰 초당 약 0.1 m로 닿습니다.

땅 플립 정책은 한 바퀴만 돌아도 되는데, 탄력으로 두 바퀴를 돌고 수평에서 멈추는 쪽을 스스로 찾았습니다. 화면에 실제 바퀴 수가 표시됩니다.

## 한계

- 땅 위 주행은 게임용 근사입니다. 바퀴 물리 대신 차체 마찰을 낮추고 구동·조향을 외력으로 흉내 냅니다. 비행과 RL은 학습 환경과 같은 물리입니다.
- 공중 트리플 플립, 공중 앞구르기 더블은 기존 정책으로 안정적이지 않아 막아 두었습니다.
- 막 던지기의 약 3분의 1은 체공 시간 안에 회전을 잡을 수 없어 세게 닿거나 넘어집니다.
- 노즐이 0~1 사이로 연속해서 열린다고 가정합니다. 실제 솔레노이드 밸브는 켜짐/꺼짐뿐입니다.

## 웹 버전

`rl_landing/web/`에 있습니다. 물리(강체·노즐·밸브 지연·가스)와 게임 로직을 자바스크립트로 옮기고, 세 정책의 가중치를 `policies.json`으로 내보내 브라우저에서 실행합니다. 화면은 three.js로 그립니다.

- MuJoCo와 비교: 정책 출력 오차 0.000005 이하, 0.6초 비행 후 위치 오차 1 mm
- 바닥·코스 충돌은 단순화한 모델이라 부딪히는 느낌은 Python 버전과 조금 다릅니다.
- 폰에서는 화면 버튼으로 조작합니다.

빌드와 배포:

```
cd rl_landing/web
python3 build.py && cp policies.json dist/
cp dist/index.html dist/policies.json ../../docs/
```
