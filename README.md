# Cold-Gas Roadster

냉가스 노즐 8개를 단 2.8 kg짜리 차를 직접 몰고, 띄우고, 뒤집는 게임입니다. 착지와 플립은 강화학습(PPO)으로 학습한 자동조종이 맡습니다. 물리는 MuJoCo로 계산합니다.

**브라우저에서 바로 하기:** https://gggg1730.github.io/rcgas/
(웹 버전은 같은 게임을 자바스크립트로 옮긴 것입니다. 아래 [웹 버전](#웹-버전) 참고)

---

## 실행

Python 3.10 이상, macOS(Apple Silicon)에서 확인했습니다.

```
cd rl_landing
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python game.py
```

전용 창을 직접 띄우므로 `mjpython`이 아니라 `python`으로 실행합니다. 창이 뜨면 한 번 클릭해 포커스를 잡은 뒤 키를 누르세요.

```
.venv/bin/python game.py --speed 0.5      # 0.5배속으로 시작
```

## 조작

| 키 | 땅 위 | 공중 |
|---|---|---|
| W / S | 가속 / 후진 | 앞 / 뒤로 기울여 이동 |
| A / D | 조향 | 좌 / 우로 이동 (기울이기 + 옆 노즐) |
| Q / E | 제자리 회전 | 왼쪽 / 오른쪽 회전 |
| Space | 떠오르기 | 상승 |
| C | | 수평을 맞추며 천천히 착지 |
| L | | RL 자동 착지 |
| F | RL 점프 옆구르기 (멈춘 상태에서) | RL 공중 옆구르기 (0.8 m 이상), 도는 중 한 번 더 누르면 더블 |
| G | RL 점프 앞구르기 (멈춘 상태에서) | RL 공중 앞구르기 (1.0 m 이상) |
| X | 차를 뒤집고 돌리며 허공으로 던짐, RL이 받아서 착지 | 같음 |
| T | 가스 무한 ↔ 실제 탱크 190 g | |
| − / = | 배속 0.1 · 0.25 · 0.5 · 1 · 2배 | |
| 1 2 3 4 | 카메라: 추격 · 옆 · 멀리 · 운전석 | |
| 5, 마우스 드래그 | 자유 시점 (왼쪽 드래그 회전, 오른쪽 드래그 이동, 휠 줌) | |
| R / P / Esc | 처음부터 / 일시정지 / 종료 | |

공중에서 키를 놓으면 자동으로 수평이 되고, 수평 속도를 죽인 뒤 그 자리에 떠 있습니다 (드론의 자세 유지 모드와 같습니다).

## 코스

출발점(0 m) → 경사로(3 m) → 단상 30 cm(10 m) → 단상 60 cm(12.5 m) → 벽(15 m) → 착지 패드(17.5 m)

경사로를 빠르게 타면 날아오릅니다. 단상 위에서도 RL 착지와 플립이 동작합니다.
